# React + Vite — Netlify Deployment

This project is prepared for deployment on Netlify.

## Netlify

1. Upload this project to a Git repository (GitHub/GitLab/Bitbucket), then connect the repository to Netlify.
2. Netlify will use the included `netlify.toml`.
3. Build command: `npm run build`
4. Publish directory: `dist`

## Local development

```bash
npm install
npm run dev
```
