# 20-Week Strength & Athletic Coach — React + Vite

A React/Vite rebuild of the 20-Week Strength & Athletic Plan.

## Included
- Dashboard, workout mode, calendar, progress and exercise library
- 20-week phase roadmap
- Set-by-set tracking, reps/load/RPE-ready UI, notes
- Rest timer and workout timer
- Streaks, PRs, achievements-ready state model
- Adaptive progression foundation
- Equipment profile and exercise alternatives
- 3D-coach style interactive viewer UI
- Body measurements and local progress photos
- Sleep, energy, recovery, hydration and nutrition state
- Themes, dark mode, accent colors, reduced motion
- JSON export/import and reset controls
- PWA manifest + service worker
- Responsive desktop/tablet/mobile layout

## Run
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Production build
```bash
npm run build
npm run preview
```

The build was not generated in this environment because external npm package installation is unavailable here; the project is intentionally supplied as a normal Vite source project so it can be installed/built on a machine with npm registry access.
